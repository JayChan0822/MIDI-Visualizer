2026-05-04 v2.3.0

  • 新增：节拍器功能，支持工具栏开关与 Woodblock / Click 两种音色切换。
  • 新增：导入 MIDI 后自动解析 Tempo Map，节拍器与小节标尺现已支持跟随速度轨同步。
  • 新增：上方轨道区支持 DAW 风格缩放操作，按 Command + 滚轮可横向缩放时间轴，按 Command + Option + 滚轮可纵向缩放轨道高度。
  • 优化：播放 / 停止 / 录音 / 节拍器按钮改为极简图标样式，transport 区更紧凑。
  • 优化：MIDI 设备接入诊断信息与热插拔重绑定逻辑，便于排查键盘识别问题。

2026-02-02 v2.2.0 (Performance Hotfix)

  • 新增：白色主题（在设置背景右侧的齿轮中切换）
  • 优化：移除全局相机阻尼 (Damping)，彻底解决播放时的画面抽动与掉帧感，实现丝滑移动。
  • 优化：模型预览窗口关闭阻尼，提升自定义模型预览时的操作流畅度。
